# svgSave

## Project Overview

svgSave is a web-based SVG project focused on making SVG-related tasks simpler and more accessible through a straightforward browser-based interface.

The project is being developed as part of the **Project Better Tomorrow** initiative, where the goal is to identify a practical daily friction and develop a simple digital intervention to address it.

## Problem / Daily Friction

Working with SVG files can become inconvenient when users need a simple way to work with SVG content without dealing with unnecessarily complex workflows.

The project explores how a lightweight web application can reduce this friction by providing a simple and accessible SVG-focused workflow.

AI tools are being used as a divergence and ideation partner during the development process.

The AI-assisted workflow includes:

1. Exploring possible solutions to the identified user friction.
2. Generating alternative approaches for the SVG application.
3. Comparing possible UI and implementation ideas.
4. Selecting suitable ideas based on project requirements and feasibility.
5. Reviewing suggestions critically instead of accepting AI-generated outputs without verification.

AI-generated suggestions are treated as ideas and are manually reviewed before being incorporated into the project.

## Technical Direction

The project is implemented as a web application.

The current technical direction focuses on:

* Browser-based interaction.
* SVG-focused functionality.
* Client-side user interaction.
* A simple and accessible user interface.
* Future SVG manipulation and export capabilities.

The technical implementation will be expanded in subsequent milestones as the project progresses.

## User Validation Plan

The project will be validated with potential users who regularly work with SVG or similar graphical assets.

The validation process will focus on:

* Ease of understanding the interface.
* Ease of completing the intended SVG workflow.
* Time required to complete common tasks.
* User difficulties and confusion.
* Suggestions for improvement.

Feedback collected from users will be used to refine the interface and functionality.
